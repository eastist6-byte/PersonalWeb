1 李群及其表示

1.3 闭线性群

定义 1.6 (闭线性群). 设 \(F\) 为 \(\mathbb{R}\) 或 \(\mathbb{C}\)，记 \(\mathrm{GL}(n,F)\) 为 \(n\times n\) 可逆矩阵构成的一般线性群. \(\mathrm{GL}(n,F)\) 的闭子群 \(G\) 称为实或复的闭线性群.

例 1.1 (常见闭线性群). 以下是一些重要的闭线性群：

  • 特殊正交群：\(\displaystyle SO(n) = \{ R \in \mathrm{GL}(n,\mathbb{R}) \mid R R^T = I,\ \det R = 1 \}\).
  • 酉群：\(\displaystyle U(n) = \{ U \in \mathrm{GL}(n,\mathbb{C}) \mid U^* U = I \}\)，其中 \(U^*\) 表示共轭转置.
  • 特殊酉群：\(\displaystyle SU(n) = \{ U \in U(n) \mid \det U = 1 \}\).
  • 特殊线性群：\(\displaystyle SL(n,F) = \{ A \in \mathrm{GL}(n,F) \mid \det A = 1 \}\)，其中 \(F = \mathbb{R}\) 或 \(\mathbb{C}\).

定义 1.7 (闭线性群的李代数). 设 \(G \subset \mathrm{GL}(n,F)\) 是一个闭线性群. 称

\[ \mathfrak{g} = \{\, c'(0) \mid c: \mathbb{R} \to G \text{ 光滑},\ c(0)=I \,\} \]

为 \(G\) 的李代数. 特别地，一般线性群 \(\mathrm{GL}(n,F)\) 的李代数是全体 \(n\times n\) 矩阵构成的线性空间，记为 \(\mathfrak{gl}(n,F)\).

例 1.2 (相应李代数的具体形式). 上述闭线性群的李代数分别由以下矩阵空间给出：

  • \(\displaystyle \mathfrak{so}(n) = \{ X \in \mathfrak{gl}(n,\mathbb{R}) \mid X^T + X = 0 \}\)（实反对称矩阵）.
  • \(\displaystyle \mathfrak{u}(n) = \{ X \in \mathfrak{gl}(n,\mathbb{C}) \mid X^* + X = 0 \}\)（反厄米特矩阵）.
  • \(\displaystyle \mathfrak{su}(n) = \{ X \in \mathfrak{u}(n) \mid \operatorname{tr}(X) = 0 \}\)（迹为零的反厄米特矩阵）.
  • \(\displaystyle \mathfrak{sl}(n,F) = \{ X \in \mathfrak{gl}(n,F) \mid \operatorname{tr}(X) = 0 \}\)，其中 \(F = \mathbb{R}\) 或 \(\mathbb{C}\)（迹为零的矩阵）.

引理 1.7. 存在 \(\mathfrak{gl}(n,\mathbb{C})\) 中 \(0\) 的开邻域 \(U\) 和 \(\mathrm{GL}(n,\mathbb{C})\) 中 \(I\) 的开邻域 \(V\)，使得 \(\exp : U \to V\) 是微分同胚.

证明. 由命题1.6，映射 \(\exp: M_n(\mathbb{C}) \to M_n(\mathbb{C})\) 光滑. 将 \(M_n(\mathbb{C})\) 视为实 \(2n^2\) 维向量空间 \(\mathbb{R}^{2n^2}\)，取一组标准基 \(\{E_1,\dots,E_{2n^2}\}\)，其中每个 \(E_j\) 对应某个矩阵位置上的实部或虚部为 1、其余为 0. 设 \(x_i\) 为对应的坐标函数， \(x_i(A)\) 表示 \(A\) 在基 \(E_i\) 下的坐标.

在 \(X=0\) 处，Jacobi 矩阵的元素为

\[\begin{aligned} \left.\frac{\partial x_i(e^X)}{\partial x_j}\right|_{X=0} &= \frac{d}{dt} x_i\bigl(e^{t E_j} \bigr) \Big|_{t=0}= x_i\!\left( \frac{d}{dt} e^{t E_j} \right) \Big|_{t=0}=x_i\!\bigl( E_j e^{t E_j} \bigr) \Big|_{t=0}\\ &=x_i(E_j I) = x_i(E_j)=\delta_{ij}. \end{aligned}\]

第一个等号因为偏导数等于沿坐标方向的方向导数，第二个等号是因为坐标函数是线性的. 从而 Jacobi 矩阵在 \(X=0\) 处为单位矩阵，故微分 \(d\exp_0\) 可逆.

根据反函数定理，存在 \(0\) 的开邻域 \(U\) 和 \(\exp(0)=I\) 的开邻域 \(V\)，使得 \(\exp|_U : U \to V\) 是微分同胚. □

注 1.2. 关于线性映射交换求导符号. 设 \(x_i: \mathbb{R}^m \to \mathbb{R}\) 是一个线性映射，\(\gamma(t)\) 是一条光滑曲线，取值于 \(\mathbb{R}^m\). 则复合函数 \(x_i(\gamma(t))\) 的导数为

\[ \frac{d}{dt} x_i(\gamma(t)) = \lim_{h\to 0} \frac{x_i(\gamma(t+h)) - x_i(\gamma(t))}{h}. \]

由于 \(x_i\) 是线性的，有

\[ x_i(\gamma(t+h)) - x_i(\gamma(t)) = x_i\bigl(\gamma(t+h)-\gamma(t)\bigr). \]

又因为线性性允许将数乘提出来：

\[ \frac{1}{h} x_i\bigl(\gamma(t+h)-\gamma(t)\bigr) = x_i\!\left(\frac{\gamma(t+h)-\gamma(t)}{h}\right). \]

因此

\[ \frac{d}{dt} x_i(\gamma(t)) = \lim_{h\to 0} x_i\!\left(\frac{\gamma(t+h)-\gamma(t)}{h}\right). \]

线性映射在有限维空间中是连续的，所以极限可以放进函数内部：

\[ = x_i\!\left( \lim_{h\to 0} \frac{\gamma(t+h)-\gamma(t)}{h} \right) = x_i(\gamma'(t)). \]

引理 1.8. 若 \(c(t)\) 是 \(\mathrm{GL}(n,\mathbb{C})\) 中的光滑曲线，满足 \(c(0)=I\)，\(c'(0)=X\)，那么对定义域中任意 \(t\)有

\[ \lim_{k \to \infty} c\left(\frac{t}{k}\right)^k = e^{tX}. \]

证明. 由泰勒展开，\(c(h)=I+hX+o(h)\)（\(h\to0\)）. 取 \(h=t/k\)，得

\[ c\left(\frac{t}{k}\right)=I+\frac{tX}{k}+o\!\left(\frac{1}{k}\right) = I+\frac{1}{k}\bigl(tX+o(1)\bigr). \]

记 \(A_k=tX+o(1)\)，则 \(A_k\to tX\)，且

\[ c\left(\frac{t}{k}\right)^k = \left(I+\frac{A_k}{k}\right)^k \to e^{tX}, \]

最后一步利用了矩阵指数的极限公式 \(\lim_{k\to\infty}(I+\frac{A_k}{k})^k = e^{\lim A_k}\). □

命题 1.9. 设\(G\)是闭线性群，\( \mathfrak{g}\)是对应的李代数，若\(X\in \mathfrak{g}\)，则\(e^X \in G\). 从而

\[ \mathfrak{g}=\{X\in \mathfrak{gl}(n,\mathbb{C})|e^{tX}\in G, \forall t \in \mathbb{R} \}. \]

证明. 按定义，设\(X\in \mathfrak{g}\)，存在\(G\)中光滑曲线\(c(t)\)，使\(c(0)=I,c^{\prime}(0)=X\). 由引理1.8，对任意\(t\)，有\(\lim_{k \to \infty} c\left(\frac{t}{k}\right)^k = e^{tX}\). 又因为\(G\)是\( \mathrm{GL}(3, \mathbb{C})\)的闭子集，所以序列极限依旧在\(G\)中，也即\(e^{tX} \in G\)对定义域中任意的\(t\)成立. 对指数再进行次方，由于群封闭，可以将\(t\)扩充至整个\(\mathbb{R}\).

另一方面，若\(X\)满足对一切实数\(t\)又\(e^{tX}\in G\)，则\(c(t)=e^{tX}\)是\(G\)中光滑曲线，满足\(c(0)=I,c^{\prime}(0)=X\). □
